# 關於這個部落格

嗨，我是 **Kevin Liu（leozzmc）**，這裡是我記錄技術學習與實作的地方。

這個部落格的內容大致涵蓋：

- **資安 / CTF**：CTF writeup（GaianSpace、STARPWN 等）、滲透測試與防禦筆記
- **無線電 / 太空**：LoRa、Meshtastic、SDR、衛星通訊與 RF 訊號分析
- **雲端 / DevOps**：AWS、Kubernetes、Terraform、CI/CD、Serverless 實作
- **演算法 / 刷題**：資料結構筆記與 LeetCode 題解
