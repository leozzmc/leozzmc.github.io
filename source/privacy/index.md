本隱私權政策說明當你造訪本部落格（`leozzmc.github.io` 及其所屬網域，以下稱「本站」）時，資料如何被收集、使用與保護。本站為個人技術部落格，以學習與研究分享為目的。

# 本站收集的資訊

本站本身不會主動要求你提供個人身分資訊。你可以匿名瀏覽所有文章。在你瀏覽的過程中，可能有以下資料被技術性地處理：

- **伺服器紀錄**：本站託管於 GitHub Pages，GitHub 可能依其自身政策記錄標準的存取資訊（例如 IP 位址、瀏覽器類型、造訪時間），詳見 [GitHub 隱私權聲明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)。
- **瀏覽量統計**：本站可能顯示匿名的造訪人次與瀏覽次數等彙總數據，不會用於識別個人。
- **本機儲存**：本站可能使用瀏覽器的 `localStorage` 來記住你的偏好（例如深色模式、語言切換），這些資料僅儲存在你的裝置上，不會傳送給本站或第三方。

# Cookie 與第三方服務

本站可能使用或嵌入第三方服務，這些服務可能會設定它們自己的 Cookie：

- **Google AdSense（若啟用）**：本站未來可能透過 Google AdSense 顯示廣告。Google 及其合作夥伴會使用 Cookie，根據你造訪本站或其他網站的紀錄來放送廣告。
    - Google 對廣告使用 Cookie 的說明，以及如何停用個人化廣告：[Google 廣告設定](https://adssettings.google.com/)、[Google 廣告技術與隱私權](https://policies.google.com/technologies/ads)。
    - 你也可以透過 [aboutads.info](https://www.aboutads.info/choices/) 或 [youronlinechoices.eu](https://www.youronlinechoices.eu/) 停用第三方供應商的 Cookie。
- **其他嵌入內容**：文章中可能嵌入外部圖片或連結（例如 imgur、YouTube、GitHub），這些服務有各自的隱私權政策。

你可以在瀏覽器設定中隨時封鎖或刪除 Cookie，但部分功能可能因此受影響。
